# 气球弓箭手 · Balloon Archer

卡通休闲手游风格的热气球弓箭手射击塔防。玩家乘坐在红黄条纹热气球上，吊篮里的弓箭手朝左自动射击，射破敌人背后的彩色气球即可把敌人击落。

技术栈：**Phaser 3.90 + Vite**，全部美术由 Canvas `Graphics.generateTexture` 程序化绘制，**不依赖任何图片素材**。

## 玩法

- 敌人（小兵 / 哥布林 / 铁骑士）被背后绑着的气球吊在空中，从左侧不同高度层浮空飞来。
- 射破气球 → 敌人逐层下降并加速；全部气球破掉 → 敌人坠落被击败，计入金币和分数。
- 敌人漏过右侧撞上热气球 → 扣 1 颗爱心，心归零则游戏结束。
- 每 2 波自动弹出商店，用金币升级弓箭；波次无限生成，越打越密。

## 操作

| 按键 | 作用 |
|---|---|
| `↑` `↓` / `W` `S` | 上下移动热气球，对齐敌人气球高度（核心操作） |
| 无需操作 | 弓箭手按冷却自动水平向左射击 |
| `B` | 打开 / 关闭商店（游戏自动暂停） |
| `空格` | 提前召唤下一波，金币 +20% |
| `Enter` | 游戏结束后重开 |
| `C` / `K` / `H` | 调试键：+100 金币 / 跳过本波 / 显示 FPS 与实体数 |

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物输出到 dist/
```

## 数值概览

| 敌人 | 气球数 | 气球 HP | 速度 px/s | 掉球加速 | 击杀奖励 |
|---|---|---|---|---|---|
| 小兵 | 1 | 1 | 130 | — | 5 币 / 50 分 |
| 哥布林 | 2 | 1 | 85 | 每层 +12% | 12 币 / 120 分 |
| 铁骑士 | 3 | 2 | 55 | 每层 +18% | 30 币 / 300 分 |

玩家初始 5 心、30 金币；箭伤 1、射速 0.55s、弹速 850。升级项：利箭（伤害）、连发（冷却）、多重箭（扇形齐射）、穿透、爆炸箭（范围）、强弓（弹速），价格按 `baseCost × 1.55^lv` 递增。

## 实现要点

- **命中判定没用 Arcade collider**：Arcade body 是 AABB 且不跟随精灵旋转，而气球是小圆形目标。改为每帧做「箭的线段采样点 × 气球圆心」距离检测，按弹速取 2~3 个采样点，避免高速穿模。
- **跨场景通信走 `registry.events`**（`hud:sync`、`banner`），敌人和波次回调直接调用 GameScene 方法而非 `scene.events`，避免重开时监听器叠加。
- 所有位移为手写运动学，未使用物理 body；`Scale.FIT` 有 letterbox，因此任何鼠标交互都必须经 `camera.getWorldPoint()` 换算。
